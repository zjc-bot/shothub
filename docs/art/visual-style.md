## 0. 风格定位与色彩逻辑

**一句话**：塞尔达式清新卡通——高明度、低对比、轻雾，草地嫩绿、木箱暖棕、天空浅蓝，阴影柔和、高光克制。

**色彩三角色比例（全场景面积加权）**：

| 角色 | 占比 | 载体 |
|---|---|---|
| 主色 | ~60% | 嫩绿草地 + 浅蓝天空/雾 |
| 辅色 | ~30% | 暖灰石阶/围墙 + 暖棕木箱/木桥 |
| 点缀色 | ~10% | 珊瑚红（灯塔/红球/玩家暖橙）+ 琥珀金（自发光体/HUD 强调） |

**Pastel 三原则**（本次调色的判定标准）：
1. 明度全部落在 0.6~0.95 区间，禁止纯黑/深灰（唯一例外：眼球瞳孔，用于对比）。
2. 饱和度压低：彩色物体 RGB 三通道差值 ≤ 0.45。
3. 天空色 = 雾色 = 清屏色，三者严格同值，远景物体自然融进天色。

**核心色板（设计参考，落地值见各节）**：

| 色名 | RGB(0~1) | 用途 |
|---|---|---|
| 天空蓝 Sky | (0.66, 0.80, 0.90) | 清屏/雾/环境光基调 |
| 嫩绿 Grass | (0.66, 0.87, 0.61) | 地面棋盘格 c1 |
| 深草绿 Grass2 | (0.57, 0.79, 0.52) | 地面棋盘格 c2 |
| 暖灰石 Stone | (0.80, 0.77, 0.74) | 石阶/高台/炮台垫 |
| 奶油墙 Cream | (0.88, 0.84, 0.77) | 围墙/立柱/灯塔身 |
| 暖棕木 Wood | (0.82, 0.58, 0.34) | 木箱/木桥 |
| 珊瑚红 Coral | (0.90, 0.42, 0.38) | 灯塔环带/顶、红球 |
| 琥珀金 Amber | (1.00, 0.80, 0.40) | 自发光路标/炮弹/HUD 强调 |
| 玩家橙 Player | (0.98, 0.66, 0.30) | 玩家身体 |

## 2. 光照氛围（高调低对比）

Pastel 的核心机制：**环境光抬高 + 太阳偏暖但不过强 + 雾色=天色=清屏色**。背光面不再死黑，整体像隔着柔光纱。

### 2.1 数值表

| 参数 | 现值 | **新值** | 落点 |
|---|---|---|---|
| 太阳方向 | Vec3(-0.42, -1.0, -0.28) | **Vec3(-0.42, -1.0, -0.28)**（不变） | game/app.py |
| 太阳颜色 | (1.0, 0.96, 0.88) | **(1.0, 0.98, 0.94)** | game/app.py |
| 太阳强度 | 0.85 | **1.05** | game/app.py |
| 环境光 ambient | (0.30, 0.33, 0.38) | **(0.48, 0.51, 0.56)** | graphics/renderer.py FogParams |
| 清屏色 clear_color | (0.55, 0.75, 0.92) | **(0.66, 0.80, 0.90)**（两处） | engine/core.py L61、L93 |
| 雾色 | = 清屏色（机制如此） | 同上（机制自动一致） | — |
| 雾密度 density | 0.010 | **0.008** | graphics/renderer.py FogParams |
| gamma | 2.2 | **2.2**（不变） | 同上 |
| shadow_bias | 0.0035 | **0.0035**（不变） | 同上 |

### 2.2 光源

```python

                            color=(1.0, 0.98, 0.94), intensity=1.05)

    color=(1.0, 0.94, 0.82),                       # 旧 (1.0,0.97,0.90) → 更暖
    inner_angle_deg=12.0, outer_angle_deg=22.0,
    intensity=3.2, attenuation=0.035,
    cast_shadow=True, shadow_res=1024, shadow_far=60.0)

# 灯塔扫射灯（game/world.py Lighthouse）：
color=(1.0, 0.88, 0.60),    # 旧 (1.0,0.92,0.72) → 更金
intensity=5.0,              # 旧 4.5 → 稍亮，天更亮了需要补偿
# inner 9° / outer 16° / attenuation 0.02 / shadow_res 1024 / shadow_far 55.0 全不变
```

### 2.3 FogParams 整段替换

```python
class FogParams:
    def __init__(self):
        self.ambient = (0.48, 0.51, 0.56)   # 旧 (0.30,0.33,0.38)
        self.density = 0.008                # 旧 0.010
        self.gamma = 2.2
        self.shadow_bias = 0.0035
```

> 校验：最暗受光面 ≈ ambient×albedo ≈ 0.48×0.66 ≈ 0.32（线性），gamma 2.2 后 ≈ 0.60——没有死黑，正是 pastel 的"提亮阴影"效果。最亮面 ≈ (1.05+0.5)×albedo 饱和到接近 1，草地面向太阳处会有轻微"过曝白"，符合清新水彩感。

**代码落点**：
- `_block()` 默认参数改为 `shininess=16.0, spec_strength=0.15`（旧 32/0.5），各调用处按上表覆盖。
- `_ball()` 内固定值改为 `shininess=64.0, spec_strength=0.85`（旧 56/0.75）。
- 地面 MeshRenderer 补 `cast_shadow=False`（平面不进阴影 pass，白省 4 次阴影渲染；主 pass 正常受影不受影响）。
- ground 的 MeshRenderer 需显式传 `shininess=8, spec_strength=0.05`（当前用默认 32/0.5，草地会出塑料高光）。

**材质分层逻辑**：spec_strength 全场 ≤ 0.5（球/玻璃/瞳孔三个"瓷感"例外），高光既区分材质又不过曝——pastel 柔和高光 = 低 shininess 贡献宽高光 + 低 strength 贡献弱高光。

## 4. HUD 视觉规格（pygame 可实现）

### 4.1 设计目标

现状是"左上角通栏黑条 + 平铺文字"，问题：通栏压迫画面、无层级、无圆角。新方案：**左上角悬浮圆角胶囊卡片**，带琥珀色左侧强调条，信息分三层，帮助页展开为独立卡片。

### 4.2 结构与层级

**主卡片（常驻）—— 3 行**：

| 层级 | 内容 | 颜色 | 字号 |
|---|---|---|---|
| L1 标题行 | `迷你世界 ｜ FPS 60 ｜ 视角 第一人称 ｜ 实体 24` | 强调琥珀 | 22（bold） |
| L2 状态行 | `手电筒 开 ｜ 锥角 22.5° ｜ 强度 3.20 ｜ 衰减 0.035` | 正文白 | 18 |
| L3 提示行 | `[H] 帮助  [Tab] 切换视角  [F] 手电` | 次要灰蓝 | 18 |

**帮助卡片（按 H 展开）—— 独立卡片，与主卡片垂直间距 8px**，5~6 行全部 18 号，按键 token（`[F]`、`WASD`、`空格` 等）渲染为琥珀色、说明文字为次要灰蓝（实现：正则 `\[([^\]]+)\]` 切分文本逐段渲染、累加 x 偏移，见 4.4）。

### 4.3 卡片样式

```python
# engine/hud.py —— HUD.__init__ 替换现有三色：
self.bar_color   = (16, 24, 38, 165)     # 卡片底：深夜蓝半透明（旧 10,12,18,150）
self.text_color  = (244, 248, 252, 255)  # 正文：暖白（旧 235,240,250）
self.hl_color    = (255, 214, 110, 255)  # 强调：琥珀（旧 255,220,120）
self.dim_color   = (166, 180, 198, 255)  # 次要：灰蓝（新增）
self.accent_bar  = (255, 214, 110, 255)  # 左侧强调条 = hl_color
```

| 属性 | 值 | 说明 |
|---|---|---|
| 位置 | (16, 14) | 距窗口左上角 |
| 卡片内边距 | 水平 14px（左侧强调条之后）+ 4px，垂直 10px | |
| 圆角 | `border_radius=12`（pygame.draw.rect） | |
| 左侧强调条 | 宽 4px、通卡片高、圆角侧用同色补一条 `rect(x, y, 4, h)`，与圆角卡片叠加视觉近似"侧标签" | |
| 卡片宽度 | **自适应**：`max(各行文本宽) + padding`，不再通栏 | |
| 行距 | `line_h = font.get_linesize() + 4` | |
| 卡片间距 | 8px（主卡片 ↔ 帮助卡片） | |
| 字号 | L1=22 bold、L2/L3/帮助=18（需要两个 Font 实例：`self.font_title`、`self.font_body`） | |

### 4.4 渲染伪代码（engine/hud.py render 重写指引）

```python
def render(self, lines):
    s = self.surface
    s.fill((0, 0, 0, 0))
    pad_x, pad_y, gap = 18, 10, 4
    line_h = self.font_body.get_linesize() + gap
    # 1) 逐行预渲染，取最大宽度 → 卡片 w
    # 2) pygame.draw.rect(s, self.bar_color, (16, 14, w, h), border_radius=12)
    # 3) pygame.draw.rect(s, self.accent_bar, (16, 14, 4, h))   # 左强调条
    # 4) 逐行 blit；L1 用 font_title+hl_color，L2 用 text_color，L3 用 dim_color
    # 5) 帮助行：re.split(r'(\[[^\]]+\])', text) 分段，
    #    括号段用 hl_color，其余段用 dim_color，逐段 render 并累加 x +=
    #    seg_font.size(seg_text)[0]
```

> compose_lines() 的文本内容**不用改**（中文/英文回退逻辑保留），只改 render() 的排版与配色；行结构如需拆 L3 提示行，把原第 3 行的 `(text, False)` 改为 `(text, "dim")` 或增加第三态即可，建议 highlight 三态：`True`→琥珀、`False`→正文白、`"dim"`→灰蓝。

**风险与提示（给程基岩）**：
1. 环境光从 0.30 → 0.48 会让现有阴影对比下降，属预期（pastel 需要浅阴影）；若嫌阴影太淡可微调 density 或 spotlight intensity 补偿。
2. checker cells 8→4 只改默认参数，renderer 调用 `checker_bytes()` 无参即可受益；若担心其他调用点，改在 renderer.py `_make_builtin_textures` 显式传参更稳。
3. 地面加 `cast_shadow=False` 属渲染优化，不影响物理与受影。
4. HUD 双字号需加载两个字体实例，注意 CJK 回退逻辑要跑两遍（抽一个 `_load(size)` 方法）。
5. 所有颜色都是线性空间输入 + 末端 gamma 2.2，调色时若观感偏灰，优先提 sun intensity 而非改 ambient。
