# 迷你世界 MiniWorld

一个用 **Python + pygame-ce + moderngl** 从零实现的微型 3D 游戏，包含两种模式：

- **波次挑战**：第一人称射击——持枪抵御 5 波人形 bot 进攻，带爆头判定、
  三选一成长、掉落拾取、双武器（步枪/狙击）与激光尾迹；
- **观光模式**：物理演示 demo——推箱子、打弹力球、躲炮台、被眼球凝视、
  调节手电光锥、欣赏实时阴影。

全部内容（网格/纹理/人形/枪械/UI）均由代码程序化生成，**零外部资源文件**。

> 引擎层（`engine/`）与玩法解耦，渲染层（`graphics/`）基于 OpenGL 3.3 Core
> 实现 Blinn-Phong 光照与聚光灯阴影；玩法层（`game/`）用它们搭出完整游戏。

## 🚀 快速开始

```bash
# 1. 安装依赖（Python 3.13，requirements 仅 pygame-ce + moderngl）
pip install -r requirements.txt

# 2. 启动（默认 1280x720）→ 进入页按 [1] 波次挑战 / [2] 观光模式
python main.py

# 3. 可选参数
python main.py --width 1600 --height 900   # 自定义窗口
python main.py --selftest                  # 无窗口自检（21 项断言，CI 可用）
python main.py --selftest --frames 3000    # 指定自检帧数
python main.py --glcheck                   # 真窗口 GL 合成检查（HUD 全屏 quad 铺屏）
```

也兼容 `python -m game.main`、`python game/main.py`。

> **窗口可自由缩放**（拖边缘 / 贴靠 / 最大化）。缩放时 HUD 画布、GL 视口与相机宽高比会同步重建，
> 所有居中元素按 `W/2`、`H/2` 相对锚点重排；最小尺寸 480×320。

> 环境要求：支持 OpenGL 3.3 Core 的显卡/驱动（近十年任何独显/核显均可）；
> 无显卡环境用 `--selftest`（纯逻辑自检，不创建 GL 上下文）；
> 改渲染 / HUD 贴屏后跑一次 `--glcheck`（真窗口检查 HUD 全屏 quad 是否铺满，
> 缺 GL 环境时自动 SKIP）。

## 🔫 波次挑战 · 玩法说明

**核心循环**：观察战场 → 瞄准射击（控扩散/控弹药）→ 借掩体规避火力 →
清波 → 三选一升级 → 迎接下一波（更硬/更准/更多）。5 波全清即胜，HP 归零即败。

| 系统 | 规则 |
| --- | --- |
| 敌人 | 人形持枪 bot（普通灰蓝绿 / 精英珊瑚红重甲），5 波共 40 只：HP 40→100、精英 0→3、精准渐升；命中分躯干/爆头（×2.5） |
| 步枪 MW-1 | 全自动 7.5 发/s，躯干 26 / 爆头 65，弹匣 30 + **初始备弹 60**，换弹 1.6s，连射扩散 bloom + 移动惩罚 |
| 狙击 SR-1 | 栓动 1 发/1.5s，躯干 260 / 爆头 650，弹匣 5 + 备弹 15；**精英重甲减伤 50%**（一发打不死精英）；右键开镜 0.8s（慢），开镜后 FOV 62°→18° 指哪打哪 |
| 弹药经济 | 波间**不再**自动补弹——bot 死亡掉落血包（+30 HP）或弹药包（步枪 +30 / 狙击 +5 备弹），精英双掉，走近自动拾取（满血不拾血包） |
| 波次升级 | 每清一波三选一：`[1]` 生命上限 +25 / `[2]` 火力 ×1.25 / `[3]` 防护 +30 且减伤 +8%（上限 40%）；8 秒未选自动选生命 |
| 击退 | 中弹会沿弹道后退：你防护高几乎不动，普通兵明显踉跄，精英减半，木箱会被打飞 |
| 生存 | HP 100，脱战 4s 后 10 HP/s 回复；间隙补给 +30 HP |

### 波次挑战（交战 / 间隙）

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移动（方向由当前相机朝向决定） |
| 鼠标移动 | 转向瞄准 |
| 鼠标左键（按住） | 射击。MW-1 全自动连发；SR-1 栓动单发 |
| 鼠标右键（按住） | **仅狙击 SR-1 有效**：开镜，0.8s 渐进，FOV 62°→18°。步枪按右键无反应 |
| `Shift` | 疾跑（5.0 → 8.2 m/s，扩散惩罚同步升到 ×2.2）**仅站立可用** |
| `空格` | 跳跃（**仅站立可用**） |
| `Ctrl`（按住） | 下蹲 |
| `C` | 切换下蹲 |
| `Z` | 切换趴下 |
| `R` | 换弹（MW-1 1.6s / SR-1 2.5s；弹匣打空会自动触发） |
| `Q` | **循环**切换武器（MW-1 ⇄ SR-1） |
| `1` / `2` | **直选**武器：`1` = MW-1 步枪，`2` = SR-1 狙击 |

切枪有 0.4s 举枪时间，期间不能开火，并会**取消正在进行的换弹**。

### 角色姿态（下蹲 / 趴下）

`Ctrl` 按住下蹲、`C` 切换下蹲、`Z` 切换趴下。姿态改变**碰撞体高度、视点高度、
移动速度**，三者平滑过渡（约 0.15s），摄像机不会瞬移。

| 姿态 | 碰撞体半高 | 视点高度 | 移速 | 疾跑/跳 | 武器晃动 |
| --- | --- | --- | --- | --- | --- |
| 站立 | 0.90m | 0.72m | 100% | 可 | 100% |
| 下蹲 | 0.55m | 0.37m | 52% | 不可 | 100% |
| 趴下 | 0.26m | 0.08m | 20% | 不可 | **25%** |

- **趴下换稳定**：武器摆动振幅与视角滞后都压到 25%，远距离点射更容易。
- **起身受阻**：头顶被掩体/箱子挡住时无法起身（保持原姿态），离开掩体后自动可站起。
- **滞空不能切姿态**，避免半空变矮导致穿地。
- 姿态在左下 HP 卡上方以小字显示当前状态与移速百分比。

### 间隙补给页（三选一升级）

清完一波后进入 8s 间隙，中央弹出升级卡片。**此时数字键含义改变**：

> 注意：从进入页按 `1` 开局后也有一次"间隙"，但那一次只有 **3s 倒计时**（顶部横幅显示"准备迎战 · 第 1 波 3s"），
> **不弹升级卡片**，此时 `1`/`2` 仍是切枪。只有清完一波后的间隙才有三选一。

| 按键 | 功能 |
| --- | --- |
| `1` | 生命强化：HP 上限 +25，且立即回复 25 HP |
| `2` | 火力强化：所有武器伤害 ×1.25（可累乘） |
| `3` | 防护强化：护甲 +30，且减伤 +8%（上限 40%） |
| 什么都不按 | 8 秒倒计时结束**自动选 `1`**，结算页记为"生命(自动)" |

> ⚠️ **升级窗口期间 `Q` 与 `1`/`2` 切枪全部失效**（`1`/`2` 已被升级占用，整个切枪分支被跳过）。
> 选定（或超时自动选定）之后自动恢复。

### 退出确认页

游戏结束后**不需要去任务管理器杀进程**——任何页面都有路可回：

```
        ┌──────────────────────────────────────────┐
        │            要退出游戏吗？                 │
        │   [Enter] 确认退出      [Esc] 返回上一页   │
        │   [T] 回到标题页（继续玩）                │
        └──────────────────────────────────────────┘
```

| 按键 | 功能 |
| --- | --- |
| `Enter` / `小键盘 Enter` / `空格` | **确认退出**，结束进程（唯一真正关窗口的入口） |
| `Esc` | 取消，返回进入确认页之前的状态 |
| `T` | 回标题页，继续玩 |

> 进入方式：标题页 / 结算页 / 退出确认页按 `Esc`。交战与观光中鼠标处于捕获状态，
> `Esc` 仍只释放鼠标（防误触）；再按一次才弹确认页。
> 退出确认页会**冻结世界模拟**（读确认框时不会被 bot 打死）。

### ⚠️ 四个容易踩的坑

1. **`1` / `2` 一键两义** —— 战斗中是"直选武器"，间隙弹出升级卡片时是"选强化"。看屏幕中央有没有卡片。
2. **`R` 一键三义** —— 战斗中换弹 / 观光模式重置世界 / 结算页重开一局。
3. **`Esc` 不会误杀进程** —— 标题页/结算页按 `Esc` 弹确认页，要按 `Enter` 才真退出；`Esc` 第二次是取消。
4. **`Tab` 在战斗模式是调试视角** —— 切到跟随视角后**枪械模型会隐藏**（`_sync_view_model` 只在第一人称渲染枪），
   且**子弹会从跟随摄像机位置（玩家身后上方）发射**，因为 hitscan 起点取 `camera_rig.position`。
   用来旁观 bot 行为可以，当正常视角打会歪。

### 枪械切换小结

```
Q        → MW-1 ⇄ SR-1 来回循环
1 / 2    → 直接指定（1=步枪，2=狙击）
```

两把枪的差异：

| | MW-1 步枪 | SR-1 狙击 |
| --- | --- | --- |
| 开火方式 | 全自动 7.5 发/s | 栓动 1 发 / 1.5s |
| 躯干 / 爆头 | 26 / 65 | 260 / 650 |
| 弹匣 + 备弹 | 30 + 60 | 5 + 15 |
| 换弹 | 1.6s | 2.5s |
| 腰射扩散 | 0.6° | 4.0°（基本打不中） |
| 腰射后座 | 0.35° / ±0.12° | **1.90° / ±0.30°**（5.4× / 2.5×） |
| 开镜 | 无 | 右键 0.8s → 0.05°，FOV 62°→18° |
| 开镜效果 | — | 后座降到 **15%**、鼠标灵敏度降到 **35%**（1:1 镜） |
| 击退冲量 | 110 | **300**（2.7×） |
| 对精英 | 常规 | **减伤 50%**（260→130 < 160HP，一发打不死） |

> 狙击初始只有 20 发且波间不补给，靠击杀 bot 掉的弹药包（+5/个）续航。
> 步枪备弹初始 60，靠弹药包（+30/个）续航。

### 命中反馈

| 反馈 | 说明 |
| --- | --- |
| **激光尾迹** | 每发子弹从枪口到命中点的 unlit 细线，寿命 0.07s |
| **火花四溅** | 命中点生成 1 亮斑 + 4 条火花，沿命中法线半球发散，受重力下坠，以缩放趋零表现熄灭 |
| **弹痕贴片** | 打中**墙面/地面/静态掩体**时留下弹孔贴片（程序化生成的弹孔+放射裂纹+边缘羽化），存活 10s，末尾 2.5s 淡出销毁。打中 bot 或会移动的木箱**只出火花不留痕** |
| **击退** | 命中 bot 施加 `冲量/(质量+防护)` 的后退速度；狙击约为步枪 2.7 倍 |
| **准星命中标记** | 躯干/爆头/击杀三态短线，颜色与时长不同 |

## 🔬 核心技术点

- **Hitscan 判定**：slab 法 ray vs AABB（`engine/math_utils.py`），玩家/bot 双方
  射击、bot 视线（LOS）、枪械防穿墙四处复用；子弹会被掩体与木箱真实遮挡。
- **爆头与物理解耦**：引擎一个实体仅一个碰撞体，爆头改用头/躯干两个**纯数学
  AABB** 裁决（头优先补偿 0.15m），bot 物理体继续承担移动/推挤，互不干扰。
- **击退公式**：`Δv = K / (质量 + 防护)`——70kg+55 防护的玩家几乎不动，
  3kg 木箱会被一枪打飞；防护升级进一步降低后退与受伤。
- **屏幕空间头顶血条**：`project_to_screen` 把 bot 头顶 3D 点投影到 HUD，
  LOS 被掩体遮挡时不显示——零 3D 开销、无 billboard 问题。
- **固定步长物理**：1/120s 累加器步进（每帧最多 6 步防死亡螺旋），动态-动态
  碰撞按质量反比分摊位移，球体冲量式速度交换。
- **光影**：每盏投影聚光灯独立 1024² 深度 FBO，主 pass 3×3 PCF 软边 +
  距离雾 + gamma 2.2；全场聚光灯上限 3（手电/灯塔已占 2），
  枪口火光/尾迹/掉落物一律走 unlit 材质，不挤灯光预算。
- **headless 自检**：`--selftest` 模拟 3000 帧按键脚本（含自动瞄准/清波等
  debug 钩子），断言 **21 项**（双模式全链路：状态流转/刷怪/命中/爆头/受击/
  回血/换弹/波次/升级/掉落/击退/尾迹/头顶血条/狙击/败北重开），确定性随机
  种子，退出码 0/1 可直接接入 CI。
- **GL 合成检查**：`--glcheck` 起真窗口（置于屏幕外，不抢鼠标、冻结场景），
  把 HUD 换成「纯色底 + 四角标记色」图案后读回默认帧缓冲，断言**铺屏率
  100%** 且四角朝向正确。HUD 链路最后一步「Surface → 纹理 → 全屏
  TRIANGLE_STRIP quad」headless 测不到（`--selftest` 不建 GL 上下文），
  顶点顺序写错会让 HUD 只覆盖 75% 屏幕、左侧出现楔形缺口（观感即
  「蝴蝶结 / 接缝」）——详见 MEMORY.md「GL 合成层」。

## ❓ 常见问题

- **窗口黑屏 / 鼠标没反应？** 点击一次窗口捕获鼠标；Esc 释放。
- **HUD 布局（面板大小、居中、遮挡）怎么保证？** 面板尺寸由 `HUD.measure_card` 按当帧文字**实测**得出（不写死像素），并在 `draw_card_at` 内夹紧进画布；居中元素一律用 `W/2`/`H/2` 相对锚点；顶部横幅纵向位置由左上状态卡实测高度推出，1280×720 下二者横向必然重叠，写死 y 就会遮盖状态卡。改 HUD 前先读 `.workbuddy/memory/MEMORY.md` 的「HUD 布局约定」与「窗口缩放」两节。
- **看不到弹痕？** 弹痕只打在**静态**表面（墙/地面/掩体）。打 bot 身上只有火花——尸体消失后贴面弹痕会悬空。会移动的木箱同理跳过。
- **想调手感数值？** 姿态看 `game/player.py` 顶部 `POSTURE_*` 表；狙击后座/击退看 `game/weapon.py` 的 `Sniper` 类属性与 `game/combat.py` 的 `KNOCKBACK_*`；火花与弹痕看 `game/effects.py` 顶部常量（`MAX_DECALS`/`MAX_SPARKS` 是性能上限，别轻易调大）。
- **HUD 显示英文？** 系统缺少中文字体，安装任意 CJK 字体（如 Noto Sans CJK）即可。
- **报显卡不支持 OpenGL 3.3？** 远程桌面/虚拟机里常见，可改用本地运行或 `--selftest`。
- **真窗口里 HUD 面板像蝴蝶结/被斜边切断，但 HUD 截图正常？** 那是贴屏
  quad 而非布局问题（布局层的 PNG 截图必然正常，因为它不含 GL 合成）。
  跑 `python main.py --glcheck`，FAIL 信息会直接指向 `hud_verts` 顶点顺序。
- **想最快验证功能？** `python main.py --selftest`，末行 `RESULT: PASS` 即
  双模式全部链路（世界构建→物理→射击→波次→升级→掉落→重置）健康。
- **想改玩法数值？** 武器/波次/升级数值集中在 `game/weapon.py`、`game/waves.py`
  与 `design/gdd/fps-wave-mode.md`；视觉配色见 `docs/art/visual-style.md`。
